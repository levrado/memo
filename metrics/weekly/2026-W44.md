- **CI did not trigger on first pushes to the new repo.** Both Feature Builder PRs (#4, #10) needed manual `chore: re-trigger CI` empty commits. Likely a fresh-repo bootstrap artifact, but flagged in the audit to monitor. Today's CI pass rate was 50% (2/4 runs).

- **Issue/PR numbering restarted at #1.** Readers comparing this recap's PR references (#4–#13) against pre-migration recaps (#1400s) should know they are different sequences. Cumulative metrics columns preserve continuity; GitHub-visible counts do not.
